How it works

Every installer contains the server address and an enrollment token. Running it installs the agent as a service, which enrolls itself and gets all settings from this server – no questions asked. Revoking a token stops new installations with it; enrolled devices keep working.

Windows installers are not code-signed yet: SmartScreen shows "Windows protected your PC" → More info → Run anyway. Silent install: inventory-agent-setup-amd64.exe /install /quiet
